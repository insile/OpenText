##### 条件期望
- 条件期望
	- **条件期望**是[[随机变量]]在给定部分信息下的[[期望]], 是[[条件分布]]的平均值. 简单来说, 条件期望就是在已知某些信息的前提下, 对随机变量的平均值进行重新计算. 条件期望的本质是一个随机变量, 当给定的信息确定为某个具体取值时, 它退化为一个普通的期望值. 设 $(\Omega,\mathcal F,P)$ 为概率空间, $X$, $Y$ 为随机变量, 条件期望 $\mathrm{E}(X\mid Y)$ 定义为一个关于 $Y$ 的随机变量 $\mathrm E(X\mid Y)=g(Y)$, 满足 $g(y)=\mathrm E(X\mid Y=y)$, 是指在 $Y=y$ 的条件下, $X$ 的平均值. 如果 $X$ 和 $Y$ 独立, 那么条件期望等于普通期望 $\mathrm{E}(X\mid Y=y) = \mathrm{E}(X)$. 如果 $X$ 和 $Y$ 有相关性, 那么条件期望会随 $y$ 变化. 严格来说, 设 $X\in L^1$ 为[[可积函数空间|可积]]随机变量, $\mathcal{G}\subset\mathcal F$ 为[[事件空间]]的子σ-代数, 则条件期望 $Z = \mathrm E[X\mid\mathcal G]$ 是一个随机变量, 满足 $\mathcal{G}$-可测和积分保持性. 对于平方可积随机变量, 条件期望是 $X$ 在子空间 $L^2(\Omega, \mathcal{G}, P)$ 上的[[正交投影]]
		- $\displaystyle \psi(x) = \mathrm{E}(X \mid Y=y) = \sum_x x p_{X\mid Y}(x\mid y)$
		- $\displaystyle \psi(x) = \mathrm{E}(X \mid Y = y) = \int_{-\infty}^{\infty} x f_{X\mid Y}(x \mid y) \mathrm{d}x$
		- $\mathrm E(X\mid Y) = \mathrm E(X\mid \sigma(Y)) = \mathrm E[X\mid\mathcal G]$
		- $\displaystyle \int_G  Z \mathrm{d}P = \int_G X \mathrm{d}P$, $G\in\mathcal G$
		- $\mathrm{E}[X] = \mathrm{E}[\mathrm{E}[X\mid Y]]$
