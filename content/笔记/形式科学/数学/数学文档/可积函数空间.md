##### 可积函数空间
- 可积函数空间
	- **可积函数空间**是由所有[[勒贝格积分|勒贝格可积函数]]组成的[[函数空间]], 记作 $L^p$, 其中 $p$ 是函数的幂指数, 当 $1 \leq p \leq \infty$ 时, $L^p$ 空间是[[巴拿赫空间]], 配备[[范数]] $\|\cdot\|_p$, 定义为函数绝对值 $p$ 次方积分的 $p$ 次根式, 特别地, 当 $p = 2$ 时, $L^2$ 空间是[[希尔伯特空间]], 配备[[内积]] $\langle \cdot,\cdot \rangle$, 定义为函数乘积积分. 设 $p$ 和 $q$ 是共轭指数, 即满足 $\frac{1}{p} + \frac{1}{q} = 1$, 则当 $1 < p < \infty$ 时, $L^p$ 的[[对偶空间]]等同于 $L^q$
		- $\displaystyle L^p = \{ f: X \to \mathbb{C} \mid \int_X |f(x)|^p \mathrm{d} \mu(x) < \infty \}$
		- $\displaystyle \|f\|_p = \left( \int_X |f(x)|^p \text{d}\mu(x) \right)^{1/p} < \infty$
	- $L^1$ 空间, 函数绝对可积
		- $\displaystyle\|f\|_1 = \int_X |f(x)| \text{d}\mu(x) < \infty$
	- $L^2$ 空间, 函数平方可积
		- $\displaystyle\|f\|_2 = \sqrt{ \int_X |f(x)|^2 \text{d}\mu(x) } < \infty$
		- $\displaystyle \langle f,g\rangle =\int _{X}f(x){\overline {g(x)}} \mathrm{d} \mu (x)$
	- $L^\infty$ 空间, 函数本质有界, 一致范数
		- $\displaystyle \|f\|_\infty = \text{ess}\sup_{x \in X} |f(x)| < \infty$


>[!example]- 可积函数空间
> - 杨氏不等式, 设 $1 < p < \infty$, 其共轭指数为 $p'$, 满足 $\frac{1}{p} + \frac{1}{p'} = 1$, 对于任意 $a, b \ge 0$
> 	- $\displaystyle ab \le \frac{a^p}{p} + \frac{b^{p'}}{p'}$
> - 赫尔德不等式, 设 $1 \le p \le \infty$, 对于可测函数 $f$ 和 $g$
> 	- $\displaystyle \|fg\|_1 \le \|f\|_p \|g\|_{p'}$
> 	- $\displaystyle \int |fg| d\mu \le \left( \int |f|^p d\mu \right)^{1/p} \left( \int |g|^{p'} d\mu \right)^{1/p'}$
> - 闵可夫斯基不等式, 设 $1 \le p \le \infty$, 对于 $f, g \in L^p(\mu)$
> 	- $\displaystyle \|f + g\|_p \le \|f\|_p + \|g\|_p$
