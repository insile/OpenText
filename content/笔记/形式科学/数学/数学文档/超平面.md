##### 超平面
- 超平面
	- **超平面**是相比几何空间 $V$ 降一维 $\dim(V) - 1$ 的子空间. 向量超平面是[[向量子空间]], 仿射超平面是[[仿射子空间]], 射影超平面是[[射影子空间]], 可用[[线性泛函|非零线性泛函]] $f:V\rightarrow \mathbb{F}$ 的[[零空间]]描述. 在三维空间中, 向量超平面就是过原点的平面, 仿射超平面是向量超平面的平移, 而射影超平面是仿射超平面的齐次化或补全到无穷远. 特别的, 仿射超平面将整个仿射空间分成两个半空间, 半空间是[[凸集]]
		- $H = \{ x \mid x\in V, f(x) = 0 \}$
		- $H = \{ x \mid x\in \mathbb{A}^n, f(x) = c \}$
		- $H = \{ [x] \mid x\in \mathbb{P}^n, f(x) = 0 \}$


>[!example]- 超平面
> - 在二维空间 R2\mathbb{R}^2R2：非零线性泛函 f(x,y)=ax+byf(x,y) = a x + b yf(x,y)=ax+by
> - 零空间 ker⁡(f)={(x,y):ax+by=0}\ker(f) = \{ (x,y) : ax + by = 0 \}ker(f)={(x,y):ax+by=0}
> - 这是一条**直线**（二维减 1），通过原点 → 向量超平面。
> - 在三维空间 R3\mathbb{R}^3R3：非零线性泛函 f(x,y,z)=ax+by+czf(x,y,z) = a x + b y + c zf(x,y,z)=ax+by+cz
> - 零空间 ker⁡(f)={(x,y,z):ax+by+cz=0}\ker(f) = \{ (x,y,z) : ax + by + cz = 0 \}ker(f)={(x,y,z):ax+by+cz=0}
> - 这是一张**平面**（三维减 1），通过原点 → 向量超平面。
