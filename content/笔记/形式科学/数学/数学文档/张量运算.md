##### 张量运算
- 张量运算
	- **张量运算**是对[[张量]]进行的[[运算]]和[[运算律]], 主要包括张量加法, 张量数乘, 张量积和张量缩并
		- 张量加法, 对两个形状相同的张量 $A = (A_{i_1 \dots i_p}^{j_1 \dots j_q})$ 和 $B = (B_{i_1 \dots i_p}^{j_1 \dots j_q})$ 求和
			- $(A + B)_{i_1 \dots i_p}^{j_1 \dots j_q} = A_{i_1 \dots i_p}^{j_1 \dots j_q} + B_{i_1 \dots i_p}^{j_1 \dots j_q}$
		- 张量数乘, 对一个张量 $A = (A_{i_1 \dots i_p}^{j_1 \dots j_q})$ 和一个标量 $\alpha$ 求积
			- $(\alpha A)_{i_1 \dots i_p}^{j_1 \dots j_q} = \alpha \cdot A_{i_1 \dots i_p}^{j_1 \dots j_q}$
		- 张量积, 将两个张量 $A^p_q$ 和 $B^r_s$ 组合成更高阶张量 
			-  $A \otimes B$ 是一个 $(p+r, q+s)$ 张量
		- 张量缩并, 对张量中一个协变指标和一个逆变指标进行求和, 生成一个阶数降低的新张量
			- 若原始张量为 $(p,q)$ 张量, 缩并后变为 $(p−1,q−1)$ 张量
