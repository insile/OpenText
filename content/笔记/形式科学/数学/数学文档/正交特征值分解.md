##### 正交特征值分解
- 正交特征值分解
	- **正交特征值分解**是一种[[矩阵因式分解]], 记作 $A = Q \Lambda Q^*$, 指[[方阵]] $A$ 分解为以[[特征值和特征向量|特征值]]为对角线元素的[[对角矩阵]] $\Lambda$ 和以[[特征值和特征向量|特征向量]]为列向量的[[正交矩阵]]或者[[酉矩阵]] $Q$. 适用于[[可正交对角化矩阵]]. 正交特征值分解本质是有限维条件下的[[谱分解]], 即方阵分解为[[正交投影矩阵]] $P_i$ 作用的叠加, 每个 $P_i$ 将向量投影到与特征值 $\lambda_i$ 对应的[[特征空间|特征子空间]]上
		- $Q=\begin{bmatrix} \mathbf{a_1}&\cdots&\mathbf{a_n}\end{bmatrix}$ 酉矩阵, 以特征向量为列向量, 可构成标准正交基
		- $\Lambda=\text{diag}(\lambda_1,\dots,\lambda_n)$ 对角矩阵, 以特征值为对角线元素
		- $Q^*=\begin{bmatrix} \mathbf{a_1}&\cdots&\mathbf{a_n}\end{bmatrix}^*$ 共轭转置
		- $\displaystyle A = Q \Lambda Q^* =\lambda_1\mathbf{a_1}\mathbf{a_1}^*+\lambda_2\mathbf{a_2}\mathbf{a_2}^*+\cdots+\lambda_n\mathbf{a_n}\mathbf{a_n}^*=\sum^{n}_{i=1}\lambda_i\mathbf{a_i}\mathbf{a_i}^*$
		- $A = Q \Lambda Q^* =\begin{bmatrix} \mathbf{a_1}&\cdots&\mathbf{a_n}\end{bmatrix}\begin{bmatrix} \lambda_1& &\\&\ddots &\\& &\lambda_n\end{bmatrix}\begin{bmatrix} \mathbf{a_1}^*\\\vdots\\\mathbf{a_n}^*\end{bmatrix}$
		- $\displaystyle A = \lambda_1 P_1 + \lambda_2 P_2 + \dots + \lambda_n P_n = \sum_{i=1}^n \lambda_i P_i$, $P_i = \mathbf{a}_i \mathbf{a}_i^*$
		- $P_i^2 = P_i$, $P_i^* = P_i$, $P_i P_j = 0$, $\sum_{i=1}^n P_i = I$
 

>[!example]- 正交特征值分解
>- 特征值分解
>	- $\begin{bmatrix}4&1\\2&3\end{bmatrix} = \begin{bmatrix}-\frac{1}{2}&1\\1&1\end{bmatrix} \begin{bmatrix}2&0\\0&5\end{bmatrix} \begin{bmatrix}-\frac{2}{3}&\frac{2}{3}\\\frac{2}{3}&\frac{1}{3}\end{bmatrix}$
>	- $\lambda_1=2$, $\mathbf{v}_1=(-\frac{1}{2},1)$
>	- $\lambda_2=5$, $\mathbf{v}_2=(1,1)$
>- 正交特征值分解
>	- $\begin{bmatrix}2&1\\1&2\end{bmatrix}=\begin{bmatrix}-\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\end{bmatrix}\begin{bmatrix}1&0\\0&3\end{bmatrix}\begin{bmatrix}-\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\end{bmatrix}$
>	- $\begin{bmatrix}2&1\\1&2\end{bmatrix}=1\begin{bmatrix}-\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}\end{bmatrix}\begin{bmatrix}-\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}\end{bmatrix}^T+3\begin{bmatrix}\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}\end{bmatrix}\begin{bmatrix}\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}\end{bmatrix}^T$
>	- $\lambda_1=1$, $\mathbf{v}_1=(-1,1)$
>	- $\lambda_2=3$, $\mathbf{v}_2=(1,1)$
