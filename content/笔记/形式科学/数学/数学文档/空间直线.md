##### 空间直线
- 空间直线
	- **空间直线**是两个[[线性函数|三元一次方程]]交集对应的[[曲线]], 通过两个不同点 $(x_1, y_1, z_1)$ 和 $(x_2, y_2, z_2)$ 唯一确定一条直线, 或者任何直线都能以两个非平行[[空间平面]]相交定义. 直线的方向由向量 $\mathbf{v} = (x_2 - x_1, y_2 - y_1, z_2 - z_1)$ 描述. 直线在空间直角坐标系中有多种[[空间直线方程|方程形式]], 适用于不同场景, 并且有一些特殊的[[空间直线图形关系|图形关系]]
		- $\begin{cases}a_1 x + b_1 y + c_1 z + d_1 = 0 \\a_2 x + b_2 y + c_2 z + d_2 = 0 \end{cases}$
