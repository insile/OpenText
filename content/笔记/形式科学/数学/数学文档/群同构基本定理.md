##### 群同构基本定理
- 群同构基本定理
	- **群同构基本定理**是[[群]]的[[同构定理]], 是在[[群同态]]下连接群, [[子群]], [[正规子群]]和[[商群]]的基本工具, 可以看作是研究群结构如何分解和重组的法则. 设 $(G, \cdot)$ 和 $(H, \circ)$ 是两个群, $\varphi: G \to H$ 是群同态
		- 第一定理, 同态的核 $\ker(\varphi) \trianglelefteq G$ 是[[正规子群]], 像 $\text{Im}(\varphi) \leq H$ 是[[子群]], 并且同态的像与[[商群]] $G / \ker(\varphi)$ 是同构的
			- $G / \ker(\varphi) \cong \operatorname{Im}(\varphi)$
		- 第二定理, 设 $H \leq G$ 是[[子群]], $N \trianglelefteq G$ 是[[正规子群]], 则 $H \cap N$ 是 $H$ 的正规子群, $HN = \{ hn \mid h \in H, n \in N \}$ 是 $G$ 的子群, 并且有同构
			- $H / (H \cap N) \cong HN / N$
		- 第三定理, 设 $N \trianglelefteq H \trianglelefteq G$ 都是[[正规子群]], 则 $H/N$ 是 $G/N$ 的正规子群, 并且有同构
			- $(G / N) / (H / N) \cong G / H$
