##### 比较关系
- 比较关系
	- **比较关系**是定义在[[实数]]上的[[偏序关系]]或[[等价关系]], 用于刻画实数之间的[[线性序|大小]]. 不等关系 $\neq$ 包括偏序关系 $\leq,\geq$ 或严格偏序关系 $<,>$, 相等关系 $=$ 可从序关系定义
		- $R=\{(a,b)\mid a\leq b\}$ $R=\{(a,b)\mid a\geq b\}$ $a,b\in\mathbb{R}$ 
			- 自反性, 对于任意 $a \in S$, 有 $a \leq a$
			- 反对称性, 对于任意 $a, b \in S$, 若 $a \leq b$ 且 $b \leq a$, 则 $a = b$
			- 传递性, 对于任意 $a, b, c \in S$, 若 $a \leq b$ 且 $b \leq c$, 则 $a \leq c$
			- 加法保序性, 若 $a ≤ b$, 则 $a + c ≤ b + c$ 且 $a − c ≤ b − c$
			- 正数乘法保序性, 若 $a ≤ b$ 且 $c > 0$，则 $ac ≤ bc$ 且 $\frac{a}{c}\leq\frac{a}{c}$
			- 负数乘法反转性, 若 $a ≤ b$ 且 $c < 0$，则 $ac ≥ bc$ 且 $\frac{a}{c}\geq\frac{a}{c}$
			- 单调函数保序性, 若 $a≤b$ 且 $f(x)$ 为单调递增函数, 则 $f(a) ≤ f(b)$
			- 单调函数反转性, 若 $a≤b$ 且 $f(x)$ 为单调递减函数, 则 $f(a) \geq f(b)$
		- $R=\{(a,b)\mid a<b\}$ $R=\{(a,b)\mid a>b\}$ $a,b\in\mathbb{R}$ 
			- 反自反性, $\forall a \in S$, $a \not< a$
			- 传递性, 若 $a < b$ 且 $b < c$, 则 $a < c$
		- $R=\{(a,b)\mid a\leq b\land a\geq b\}$ $a,b\in\mathbb{R}$
			- 自反性, $\forall a \in S$, $a = a$
			- 对称性, 若 $a = b$, 则 $b = a$
			- 传递性, 若 $a = b$ 且 $b = c$, 则 $a = c$
			- 函数保序性, 若 $a=b$, 则 $f(a) = f(b)$
