##### 傅里叶级数部分和
- 傅里叶级数部分和
	- **傅里叶级数部分和**是[[傅里叶级数]]的[[序列级数|有限和]], 可以看作原函数的有限项近似, 具有[[卷积]]形式, 用于分析傅里叶级数的[[傅里叶级数收敛性|收敛性]]. 设 $f(x) \in L^1([-\pi, \pi])$ 是周期为 $2\pi$ 的可积函数, 则可定义傅里叶级数, 部分和 $S_N(f)$ 是傅里叶级数的前 $2N+1$ 项和, 每一个 $N$ 的增加, 都代表在近似中引入了一个更高频率的细节. 部分和可以重新表述为原函数 $f$ 与某个核函数 $K_N$ 的卷积, 其中核函数将级数求和过程转化为积分形式, 同时也决定了卷积的加权方式, 选择不同的核就是选择不同的求和方法. 狄利克雷核是最原始直接的核, 对应于普通意义下的傅里叶部分和, 其振荡性质解释了逐点收敛及吉布斯现象. 费耶核通过对部分和取切萨罗均值进行平滑化, 保证了连续函数情形下的一致收敛. 泊松核则通过调和延拓将周期函数在单位圆内平滑化, 使傅里叶级数在边界收敛, 同时连接边界值与圆盘内的[[调和函数]]
		- $\displaystyle f(x) \sim \sum_{n=-\infty}^{\infty} c_n e^{i n x}$, $\displaystyle c_n = \frac{1}{2\pi} \int_{-\pi}^{\pi} f(x) e^{-i n x} \mathrm{d}x$
		- $\displaystyle S_N(x) = \sum_{n=-N}^{N} c_n e^{i n x} = \frac{a_0}{2} + \sum_{n=1}^{N} (a_n \cos nx + b_n \sin nx)$
		- 卷积形式 $\displaystyle S_N(x) = (f * K_N)(x) = \frac{1}{2\pi} \int_{-\pi}^{\pi} f(t) K_N(x-t) \mathrm{d}t$
		- 狄利克雷核 $\displaystyle D_N(x) = \sum_{n=-N}^{N} e^{i n x} = \frac{\sin((N+1/2)x)}{\sin(x/2)}$
		- 费耶核 $\displaystyle F_N(x) = \frac{1}{N+1}\sum_{k=0}^N D_k(x) = \frac{1}{N+1}\left(\frac{\sin\!\big(\tfrac{N+1}{2}x\big)}{\sin(x/2)}\right)^2$
		- 泊松核 $\displaystyle P_r(x) = \sum_{n=-\infty}^{\infty} r^{|n|} e^{i n x} = \frac{1-r^2}{1-2r \cos x + r^2}$
