##### 解析同构
- 解析同构
	- **解析同构**是[[解析函数|解析]]意义下的[[同构]], 几何上也称为[[共形映射]], 解析同构本质上就是一个全局的保角变换. 设 $U,V\subset\mathbb C$ 为开集, 若存在映射 $f:U\to V$, 满足 $f$ 在 $U$ 上解析, $f$ 是[[双射]], $f^{-1}:V\to U$ 也解析, 则称 $f$ 是 $U$ 到 $V$ 的解析同构, 并称 $U$ 与 $V$ 解析同构. 当 $U$ 和 $V$ 是同一个区域时, 也称为解析自同构, 可构成[[群|自同构群]]. 若 $f$ 为[[复函数]], 则 $f$ 只要是[[全纯函数|全纯]]的[[单射]], 它的逆映射 $f^{-1}$ 就自动是全纯的, 但[[实函数]]不成立. 解析同构主要讨论[[复平面]] $\mathbb{C}$, [[复平面|上半平面]] $\mathbb{H} = \{ z \in \mathbb{C} \mid \text{Im}(z) > 0 \}$, [[复数圆盘|单位圆盘]] $\mathbb{D} = \{ z \in \mathbb{C} \mid |z| < 1 \}$, 以及[[黎曼球面]] $\hat{\mathbb{C}} = \mathbb{C} \cup \{\infty\}$. [[黎曼映射定理]]指出任何单连通区域与单位圆盘解析同构, 其中[[凯莱变换]]是上半平面与单位圆盘之间的一个标准同构. 而自同构群主要有单位圆盘的自同构群 $\text{Aut}(\mathbb{D})$, 上半平面的自同构群 $\text{Aut}(\mathbb{H})$, 复平面的自同构群 $\text{Aut}(\mathbb{C})$ 和黎曼球面的自同构群 $\text{Aut}(\hat{\mathbb{C}})$, 都是某种形式的[[分式线性变换]], 并且与某种[[李群|矩阵群]]同构. 具体来说, $\text{Aut}(\mathbb{D})$ 全部由纯旋转与布拉施克因子复合而成. 任何一个把单位圆盘变成它自己的自同构, 必定是先用分式线性变换把某个内部点挪到中心, 再绕中心转个圈. $\text{Aut}(\mathbb{H})$ 是全实系数的分式线性变换. $\text{Aut}(\mathbb{C})$ 是复系数的[[仿射变换|整式线性变换]]. $\text{Aut}(\hat{\mathbb{C}})$ 是最完整的全局分式线性变换
		- $\displaystyle \text{Aut}(\mathbb{D}) = \left\{ f(z) = e^{i\theta} \frac{z - a}{1 - \bar{a}z} \ \middle|\  \theta \in \mathbb{R}, \, |a| < 1 \right\}  \cong \text{PSU}(1,1)$
		- $\displaystyle \text{Aut}(\mathbb{H}) = \left\{ f(z) = \frac{az + b}{cz + d} \ \middle|\  a, b, c, d \in \mathbb{R}, \, ad - bc > 0 \right\} \cong \text{PSL}(2, \mathbb{R})$
		- $\text{Aut}(\mathbb{C}) = \left\{ f(z) = az + b \ \middle|\  a, b \in \mathbb{C}, \, a \neq 0 \right\} \cong \mathrm{Aff}(1, \mathbb{C})$
		- $\displaystyle \text{Aut}(\hat{\mathbb{C}}) = \left\{ f(z) = \frac{az + b}{cz + d} \ \middle|\  a, b, c, d \in \mathbb{C}, \, ad - bc \neq 0 \right\} \cong \text{PSL}(2, \mathbb{C})$
