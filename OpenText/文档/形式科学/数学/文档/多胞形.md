##### 多胞形
- 多胞形
	- **多胞形**是由有限个面拼合而成的[[几何图形]], 是二维[[多边形]]与三维[[多面体]]在任意维度上的推广. 凸多胞形是凸的多胞形. 设 $\mathbb{R}^n$ 是 $n$ 维[[欧氏空间|实]][[仿射空间]], $S = \{v_1, v_2, \dots, v_k\}$ 是 $\mathbb{R}^n$ 中一个有限点集, 则由 $S$ 生成的凸多胞形 $P$ 定义为其[[凸包]], 记作 $P = \text{conv}(S)$. [[单纯形]]是最简单的凸多胞形
		- $\displaystyle P = \text{conv}(S) = \left\{ \sum_{i=1}^k \lambda_i v_i \ \middle|\ \sum_{i=1}^k \lambda_i = 1, \lambda_i \ge 0 \right\}$
