##### 有界变差
- 有界变差
	- **有界变差**是指[[实函数|实值函数]]总变差有界. 设 $f(x)$ 是定义在闭区间 $[a, b]$ 上的实值函数, 对区间 $[a, b]$ 取任意划分 $P = \{a = x_0 < x_1 < x_2 < \dots < x_n = b\}$, 函数 $f$ 关于这个划分 $P$ 的全变差定义为相邻纵坐标差的绝对值之和 $V_a^b(f, P) = \sum_{i=1}^n \vert{}f(x_i) - f(x_{i-1})\vert{}$, 如果对 $[a, b]$ 的所有可能划分 $P$, 其全变差 $V_a^b(f, P)$ 都有一个统一的上界, 则称 $f$ 在 $[a, b]$ 上是有界变差函数, 记作 $f \in BV[a, b]$. 所有划分变差的[[确界|上确界]]称为 $f$ 在 $[a, b]$ 上的总变差, 记为 $V_a^b(f) = \sup_P \sum_{i=1}^n \vert{}f(x_i) - f(x_{i-1})\vert{} < \infty$. 简单来说, 函数在区间内虽然可以上下波动, 但所有波动距离加起来是有限的. 有界变差函数区间可加, 对线性运算封闭. 有界变差函数一定是[[有界函数]]. [[单调函数]]一定是有界变差函数, 有界变差函数可以分解为两个单调函数之差. 有界变差函数[[左右极限]]存在, 间断点只能是[[函数间断点|跳跃间断]], 最多有可数个间断点, 并且[[几乎处处]][[可导函数|可导]]. 有界变差函数和[[连续函数空间|连续函数]]互不包含. [[绝对连续]]函数一定是有界变差函数, 但反过来并不一定成立, 例如[[康托尔函数]]. 有界变差概念可直接应用于[[测度]], 勒贝格-斯蒂尔杰斯测度就是把函数的增量推广成测度, 而有界变差函数正好对应于有限符号测度, 可以建立勒贝格-斯蒂尔杰斯积分
		- $f \in BV[a,b] \iff V_a^b(f) < +\infty$
		- $f \in BV[a,b] \iff f = g - h,\text{ 其中 } g,h \text{ 在 } [a,b] \text{ 上单调递增}$
