##### 可和序列空间
- 可和序列空间
	- **可和序列空间**是由所有 $p$ 次方[[绝对收敛]]的[[序列]]构成的[[函数空间]], 并且配备特定[[范数]]构成[[赋范向量空间]]. 当 $1 \le p < \infty$ 时, 其范数为[[求和范数]] $\|\mathbf{x}\|_p = \left( \sum_{i=1}^{\infty} |x_i|^p \right)^{1/p}$, 记作 $(l^p, \|\cdot\|_p)$. 当 $p = \infty$ 时, 其范数为[[一致范数]] $\|\mathbf{x}\|_\infty = \sup_{i\geq 1} |x_i|$, 即退化为全体[[有界序列]]构成的空间, 记作 $(l^\infty, \|\cdot\|_\infty)$. 此外, $c$ 空间是[[序列极限|收敛序列空间]], $c_0$ 空间是收敛于零的序列空间, 这两个空间都是 $l^\infty$ 的闭子空间, 继承相同范数. 上述所有空间 $l^p$, $l^\infty$, $c$, $c_0$ 在各自的范数下都是都是[[巴拿赫空间]]. $l^p$, $c$, $c_0$ 空间是[[可分空间]], $l^\infty$ 空间不是可分空间. $l^2$ 空间是唯一的[[希尔伯特空间]], 其[[内积]]定义为 $\langle x, y \rangle = \sum_{i=1}^\infty x_i \bar{y}_i$. 设 $1 \leq j < k < \infty$, 则各序列空间存在严格的包含关系 $l^j \subset l^k \subset c_0 \subset c \subset l^\infty$. 设 $1 < p < \infty$, 若 $1/p+1/q=1$, 则称 $p$ 与 $q$ 为共轭指数, 此时序列空间的[[对偶空间]]呈现一定对称性, $(c_0)^* \cong l^1$, $(l^1)^* \cong l^\infty$, $(l^p)^* \cong l^q$, $(l^2)^* \cong l^2$, 但这一对称性在 $l^\infty$ 处中断, $(l^\infty)^*$ 不同构于 $l^1$, 而是严格更大的空间, 只有 $l^p$, $(1 < p < \infty)$ 空间是自反空间, 而 $l^1$, $l^\infty$, $c$, $c_0$ 空间都不是自反空间, $l^2$ 空间是自对偶的
		- $\displaystyle l^p = \left\{\{x_i\}_{i=1}^{\infty}\subset \mathbb{C} \mid \sum_{i=1}^{\infty} |x_i|^p < \infty \right\}$
		- $\displaystyle \|\mathbf{x}\|_p = \left( \sum_{i=1}^{\infty} |x_i|^p \right)^{1/p} < \infty$
