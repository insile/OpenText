##### 序列
- 序列
	- **序列**是按一定顺序排列的元素列表, 序列蕴含[[可数集|可数]]与[[良序关系|有序]]可定义为[[自然数]]上的[[映射]]. 设 $\mathbb{N}$ 是自然数集, $S$ 是任意集合, 则有限序列定义为映射 $f:\{1,2,...,n\}\to S$, $n\in\mathbb{N}^+$, 记作 $\{a_i\}_{i=1}^{n}$, 无限序列定义为映射 $f:\mathbb{N}^+\to S$, 记作 $\{a_i\}_{i=1}^{\infty}$. 序列中每个索引 $i\in \mathbb{N}^+$ 都对应一个元素 $a_i \in S$, 也称为序列的项, 每项按索引 $i$ 从小到大排列, $a_n$ 表示序列的第 $n$ 项, 描述任意第 $n$ 项的表达式 $a_n=f(n)$ 称为序列的通项公式. 此外, 序列还可用[[递推关系]]或[[生成函数]]表示, 可以选取一些项组成[[子序列]]. 序列按元素可分为[[数列]], [[函数序列]], [[集合序列]]等, 按性质可分为[[计数序列]], [[有界序列]], [[单调序列]]等, 对于不同元素可以定义相应的[[序列运算]]. 通过[[序列极限]], [[序列级数]]和[[序列积数]]可以分析无限序列的收敛行为
		- $\{a_n\}_{n\in \mathbb{N}^+}=a_1,a_2,a_3,\cdots,a_n,\cdots=\{a_n\}_{n=1}^{\infty}$


>[!example]- 序列
>- $a_n=n$
>	- $\displaystyle S_n=\frac{n(n+1)}{2}$
>- $a_n=n^2$
>	- $\displaystyle S_n=\frac{n(n+1)(2n+1)}{6}$
>- $a_n=n^3$
>	- $\displaystyle S_n = \left[\frac{n(n+1)}{2}\right]^2 = (1 + 2 + \dots + n)^2$
>- $a_n=a_1+(n-1)d$
>	- $\displaystyle S_n=\frac{n(a_1+a_n)}{2}$
>- $a_n=a_1q^{n-1}$
>	- $\displaystyle S_n=\begin{cases}na_1 & q=1\\\dfrac{a_1(1-q^n)}{1-q} & q\neq1\end{cases}$
>- $a_n=\frac{1}{n(n+1)}$
>	- $\displaystyle S_n=1-\frac{1}{n+1}=\frac{n}{n+1}$
>- $a_n=\frac{1}{n(n+2)}$
>	- $\displaystyle S_n=\frac{1}{2}\left(1+\frac{1}{2}-\frac{1}{n+1}-\frac{1}{n+2}\right)$
>- $a_n=\frac{1}{\sqrt{n}+\sqrt{n+1}}$
>	- $S_n=\sqrt{n+1}-1$
>- $a_n=n\cdot n!$
>	- $S_n=(n+1)!-1$
>- $a_n = \frac{1}{n}$
>	- $H_n = \sum_{k=1}^n \frac{1}{k} = \ln n + \gamma + O\left(\frac{1}{n}\right)$
