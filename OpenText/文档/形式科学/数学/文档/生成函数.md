##### 生成函数
- 生成函数
	- **生成函数**是指通过[[幂级数]]将[[序列]]转化为[[映射|函数]]形式, 从而简化问题的分析和求解, 由于它通常被视作形式幂级数, 因此不必考虑收敛性. 对于一个数列 $\{a_n\}$, 它的生成函数 $G(x)$ 通常定义为一个幂级数, 核心思想是将数列的每一项 $a_n$​ 编码到幂级数的系数上, 将[[序列运算|组合操作]]代数化, 通过运算直接得到答案, 而不需要穷举或逐项计算. 生成函数主要包括普通生成函数, 指数型生成函数, 还有特殊的狄利克雷生成函数
		- $\{a_n\}=a_1,a_2,a_3,\cdots,a_n,\cdots$
		- $G(x) = a_0 + a_1x + a_2x^2 + a_3x^3 + \dots = \sum_{n=0}^{\infty} a_n x^n$
		- $G(x) = a_0 + a_1 \frac{x}{1!} + a_2 \frac{x^2}{2!} + a_3 \frac{x^3}{3!} + \dots = \sum_{n=0}^{\infty} a_n \frac{x^n}{n!}$
		- $D(x) = \frac{a_1}{1^s} + \frac{a_2}{2^s} + \frac{a_3}{3^s} + \dots = \sum_{n=1}^{\infty} \frac{a_n}{n^s}$


>[!example]- 生成函数
> - 平移性质
> 	- $A(x)=a_0+a_1x+a_2x^2+\cdots=(a_0,a_1,a_2,\cdots)$
> 	- $xA(x)=a_0x+a_1x^2+a_2x^3+\cdots=(0,a_0,a_1,\cdots)$
> 	- $\frac{A(x)-a_0}{x}=a_1+a_2x+a_3x^2+\cdots=(a_1,a_2,a_3,\cdots)$
> - 线性性质
> 	- $c_n = \alpha a_n + \beta b_n$, $C(x) = \alpha A(x) + \beta B(x)$
> - 卷积性质
> 	- $c_n = \sum_{k=0}^n a_k b_{n-k}$, $C(x) = A(x) \cdot B(x)$
> - 微积分性质
> 	- $x A'(x) = \sum n a_n x^n = \{n a_n\}$
> 	- $\int_0^x A(t) dt = \sum \frac{a_n}{n+1} x^{n+1} = \{\frac{a_n}{n+1}\}$
> - 常数列 
> 	- $a_n = 1$, $A(x)=\sum x^n = \frac{1}{1 - x}$
> - 等差数列 
> 	- $a_n = n$, $A(x)=\sum n x^n = \frac{x}{(1 - x)^2}$
> - 几何数列 
> 	- $a_n = r^n$, $A(x)=\sum r^n x^n = \frac{1}{1 - rx}$
> - 斐波那契数列
> 	- $F_n=F_{n-1}+F_{n-2}$, $A(x)=\sum F_n x^n = \frac{x}{1 - x - x^2}$
