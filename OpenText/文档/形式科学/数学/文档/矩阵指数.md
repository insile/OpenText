##### 矩阵指数
- 矩阵指数
	- **矩阵指数**是一种[[矩阵函数]], 既是[[指数函数]]在[[矩阵空间]]上的推广, 也是[[指数映射]]在矩阵空间中的具体形式, 即将[[李代数]]映射回[[李群]]. 对于矩阵 $A \in \mathbb{F}^{n \times n}$, 矩阵指数可定义为[[幂级数]] $\exp(A)=e^A=\sum_{k=0}^{\infty} \frac{A^k}{k!}$, 其中 $A^k$ 为[[矩阵的幂]], 该矩阵幂级数在任意矩阵范数下绝对收敛. 矩阵指数满足多种运算律, 与[[矩阵]]的一些性质相容, 可通过[[幂零矩阵]]和[[若尔当-谢瓦莱分解]]简化计算. 矩阵指数是矩阵李群上的指数映射 $\exp: \mathfrak{g} \to G$, $X \mapsto e^X$, 它将李代数中的无穷小变换积分为李群中的有限变换
		- $\displaystyle e^A = \sum_{k=0}^{\infty} \frac{A^k}{k!} = I + A + \frac{1}{2!}A^2 + \frac{1}{3!}A^3 + \dots$, $A^0 = I$
		- 零次幂, $e^0 = I$
		- 可逆性, $(e^A)^{-1} = e^{-A}$
		- 共轭转置, $(e^X)^H = e^{X^H}$
		- 相似矩阵, $e^B = e^{PAP^{-1}} = Pe^AP^{-1}$
		- 指数乘法, $e^X e^Y = e^{X+Y}$, $XY = YX$
		- 指数的迹, $\text{tr}(e^A) = \sum_{i=1}^n e^{\lambda_i}$
		- 指数特征值, $\sigma(e^A) = e^{\sigma(A)}$
		- 指数行列式, $\det(e^A) = e^{\text{tr}(A)}$
		- 指数导数, $\frac{\mathrm{d}}{\mathrm{d}t} e^{tX} = X e^{tX} = e^{tX} X$
		- 幂零矩阵指数, $e^X = I + X + \frac{X^2}{2!} + \dots + \frac{X^{k-1}}{(k-1)!}$
		- 若尔当-谢瓦莱分解, $e^X = e^S e^N$, $X = S + N$
		- 李乘积公式, $\lim_{m \to \infty} (e^{X/m} e^{Y/m})^m = e^{X+Y}$
