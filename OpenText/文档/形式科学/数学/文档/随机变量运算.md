##### 随机变量运算
- 随机变量运算
	- **随机变量运算**是对[[随机变量]]进行的[[运算]]和[[运算律]], 定义在同一[[概率空间]]上的多个随机变量可以通过算术运算生成一个新的随机变量, 并且拥有新的[[概率分布]]以及[[期望]], [[方差]]等数字特征. 随机变量的运算本质上是[[样本空间]]上的[[可测函数]][[函数运算|运算]], 主要包括随机变量的加法, 减法, 乘法, 除法以及线性组合. 其中, 和差用于描述累积效应, 乘除用于描述相互作用或放大效应. 在分布层面, 独立随机变量的和差分布由[[卷积]]给出, 积商分布则需通过[[随机变量变换|换元]]求得, 形式通常更复杂. 在数字特征层面, 和差的期望可加性恒成立, 不需要独立性假设, 但和差的方差涉及[[协方差]]项, 只有当随机变量独立或者不相关时协方差项才消失, 方差才具有可加性. 乘积的期望也需要独立性或者不相关才能拆分为各自期望之积, 否则须引入协方差修正项. 此外, 独立随机变量之和的[[概率生成函数]], [[矩生成函数]]与[[概率特征函数]]等于各自函数之积. 如果服从某一分布族的随机变量经过加法等运算后, 分布族保持不变, 则称该分布族具有可加性或对应运算下的封闭性. 如果两个独立随机变量的线性组合具有相同的分布, 则称该分布是稳定的
		- $Z = X + Y$
			- 分布, $f_Z(z) = \int_{-\infty}^{\infty} f_X(x) f_Y(z-x) \mathrm{d}x$, $X,Y\text{ 独立}$
			- 期望, $\mathrm{E}[X + Y] = \mathrm{E}[X] + \mathrm{E}[Y]$
			- 方差, $\mathrm{Var}(X+Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) + 2\mathrm{Cov}(X,Y)$
			- 方差, $\mathrm{Var}(X+Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$, $X,Y\text{ 独立}$
			- 概率生成函数, $G_{X+Y}(s) = G_X(s)G_Y(s)$, $X,Y\text{ 独立}$
			- 矩生成函数, $M_{X+Y}(t)=M_X(t)M_Y(t)$, $X,Y\text{ 独立}$
			- 概率特征函数, $\varphi_{X+Y}(t) = \varphi_X(t)\varphi_Y(t)$, $X,Y\text{ 独立}$
		- $Z = X - Y$
			- 分布, $f_Z(z) = \int_{-\infty}^{\infty} f_X(x) f_Y(x-z) \mathrm{d}x$, $X,Y\text{ 独立}$
			- 期望, $\mathrm{E}[X - Y] = \mathrm{E}[X] - \mathrm{E}[Y]$
			- 方差, $\mathrm{Var}(X-Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) - 2\mathrm{Cov}(X,Y)$
			- 方差, $\mathrm{Var}(X-Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$, $X,Y\text{ 独立}$
			- 矩生成函数, $M_{X-Y}(t)=M_X(t)M_Y(-t)$, $X,Y\text{ 独立}$
			- 概率特征函数, $\varphi_{X-Y}(t) = \varphi_X(t)\varphi_Y(-t)$, $X,Y\text{ 独立}$
		- $Z = XY$
			- 分布, $f_Z(z) = \int_{-\infty}^{\infty} \frac{1}{\|x\|} f_X(x) f_Y\left(\frac{z}{x}\right) \mathrm{d}x$, $X,Y\text{ 独立}$
			- 期望, $\mathrm{E}[XY] = \mathrm{E}[X]\mathrm{E}[Y] + \mathrm{Cov}(X,Y)$
			- 期望, $\mathrm{E}[XY] = \mathrm{E}[X]\mathrm{E}[Y]$, $X,Y\text{ 独立}$
			- 方差, $\mathrm{Var}(XY) = \mathrm{Var}(X)\mathrm{Var}(Y) + \mathrm{Var}(X)(\mathrm{E}[Y])^2 + \mathrm{Var}(Y)(\mathrm{E}[X])^2$, $X,Y\text{ 独立}$
		- $Z = \frac{X}{Y}$
			- 分布, $f_Z(z) = \int_{-\infty}^{\infty} \|y\| f_X(zy) f_Y(y) \mathrm{d}y$, $X,Y\text{ 独立}$
			- 期望, $\mathrm{E}\left[\frac{X}{Y}\right] = \mathrm{E}[X]\mathrm{E}\left[\frac{1}{Y}\right]$, $X,Y\text{ 独立}$
