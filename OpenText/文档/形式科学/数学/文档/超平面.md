##### 超平面
- 超平面
	- **超平面**是指一个几何空间中比该空间维数低一维的子空间, 即 $n$ 维空间中的超平面是 $(n-1)$ 维的. 具体来说, 向量超平面是[[向量空间]]的[[向量子空间|子空间]], 仿射超平面是[[仿射空间]]的[[仿射子空间|子空间]], 射影超平面是[[射影空间]]的[[射影子空间|子空间]]. 例如, 在三维空间中, 向量超平面就是过原点的平面, 仿射超平面是向量超平面的平移, 而射影超平面是向量超平面的齐次化或补全到无穷远. 形式上, $n$ 维向量空间 $V$ 中的超平面是一个 $(n-1)$ 维的向量子空间, 即必须通过原点, 可用[[线性泛函]]的核空间表示, 记作 $H = \{ x\in V \mid f(x) = 0 \} = \operatorname{Ker}(f)$, 其中 $f$ 是 $V$ 上的非零线性泛函. 仿射空间 $\mathbb{A}(V)$ 中的超平面是向量超平面的平移, 不要求过原点, 记作 $H = \{ x\in \mathbb{A}(V) \mid  f(x) = c \}$. 射影空间 $\mathbb{P}(V)$ 中的超平面是向量超平面射影化后的结果, 使用齐次坐标定义, 记作 $H = \{ [x] \in \mathbb{P}(V) \mid f(x) = 0 \}$. 仿射超平面可以将整个仿射空间划分成两个[[凸集|半空间]], 也可以将两个不相交的凸集[[超平面分离定理|分离]]
		- $H = \{ x\in V \mid f(x) = 0 \} = \operatorname{Ker}(f)$
		- $H = \{ x\in \mathbb{A}(V) \mid  f(x) = c \}$
		- $H = \{ [x] \in \mathbb{P}(V) \mid f(x) = 0 \}$


>[!example]- 超平面
> - 在二维空间 $\mathbb{R}^2$, 非零线性泛函 $f(x,y) = a x + b y$
> 	- 零空间 $\operatorname{Ker}(f) = \{ (x,y) \mid ax + by = 0 \}$
> 	- 这是一条直线, 二维减一, 通过原点是向量超平面
> - 在三维空间 $\mathbb{R}^3$, 非零线性泛函 $f(x,y,z) = a x + b y + c z$
> 	- 零空间 $\operatorname{Ker}(f) = \{ (x,y,z) \mid ax + by + cz = 0 \}$
> 	- 这是一张平面, 三维减一, 通过原点是向量超平面
