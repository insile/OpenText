##### 自然数构造
- 自然数构造
	- **自然数构造**是指从更基础的数学对象出发, 按照明确的规则构建[[自然数]]. 冯诺依曼自然数是最经典的集合论构造方法, 其核心思想是将每个自然数[[递归]]定义为[[包含序|包含]]所有比它小的自然数的[[集合]]. 规定初始元素 $0$ 为空集 $0 = \emptyset$, 对于任意自然数 $n$, 定义其后继 $n+1$ 为 $n$ 与其单元素集 $\{n\}$ 的并集 $n + 1 = n \cup \{n\}$, 根据上述规则递推, 每一个自然数 $n$ 都可以表示为包含它之前所有自然数的集合. 冯·诺伊曼自然数是[[皮亚诺公理]]的一个具体模型
		- $n = \{0, 1, 2, \dots, n - 1\}$
		- $0$ 定义为空集, $0 = \emptyset = \{\}$
		- $1$ 定义为包含 $0$ 的集合, $1 = \{0\} = \{\emptyset\}$
		- $2$ 定义为包含 $0$ 和 $1$ 的集合, $2 = \{0, 1\} = \{\emptyset, \{\emptyset\}\}$
		- $3$ 定义为包含 $0$, $1$, $2$ 的集合, $3 = \{0, 1, 2\} = \{\emptyset, \{\emptyset\}, \{\emptyset, \{\emptyset\}\}\}$
		- 依此类推, $n$ 被定义为包含所有小于 $n$ 的自然数的集合
