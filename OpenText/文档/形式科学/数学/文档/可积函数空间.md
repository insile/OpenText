##### 可积函数空间
- 可积函数空间
	- **可积函数空间**是由所有 $p$ 次方[[勒贝格积分|绝对可积]]的[[可测函数|函数]]构成的[[函数空间]], 并且配备特定[[范数]]构成[[赋范向量空间]]. 当 $1 \le p < \infty$ 时, 其范数为[[积分范数]] $\|f\|_p = \left( \int_X |f(x)|^p \text{d}\mu(x) \right)^{1/p}$, 记作 $(L^p, \|\cdot\|_p)$. 当 $p = \infty$ 时, 其范数为[[一致范数]] $\|f\|_\infty = \text{ess sup}_{x \in X} |f(x)|$, 即退化为全体本质[[有界函数]]构成的空间, 记作 $(L^\infty, \|\cdot\|_\infty)$. $L^p$ 与 $L^\infty$ 空间在各自的范数下都是都是[[巴拿赫空间]], 其可分性依赖于底层测度空间, $L^p$ 空间通常是[[可分空间]], 而[[简单函数]], [[连续函数空间|紧支撑连续函数]], [[测试函数]]是其稠密子空间, $L^\infty$ 空间通常不是可分空间. $L^2$ 空间是唯一的[[希尔伯特空间]], 其[[内积]]定义为 $\langle f,g\rangle = \int_X f\bar{g}\, \mathrm{d}\mu$. 可积函数空间包含关系的方向依赖于测度空间是否有限, 如果测度空间有限 $\mu(\Omega)<\infty$, 则 $L^\infty\subset L^q\subset L^p\subset L^1$, 其中 $1\le p<q<\infty$, 也就是 $p$ 越大, 要求越严格, 例如 $L^\infty$ 要求函数几乎处处有界, 最严格. 设 $1 < p < \infty$, 若 $1/p+1/q=1$, 则称 $p$ 与 $q$ 为共轭指数, [[对偶空间]]关系有 $(L^p)^* \cong L^q$, $(L^2)^*\cong L^2$, 而 $(L^1)^* \cong L^\infty$ 需要 σ-有限测度, 只有 $L^p$, $(1 < p < \infty)$ 空间是自反空间, 而 $L^1$, $L^\infty$ 空间都不是自反空间, $L^2$ 空间是自对偶的
		- $\displaystyle L^p = \left\{ f: X \to \mathbb{C} \mid \int_X |f(x)|^p \mathrm{d} \mu(x) < \infty \right\}$
		- $\displaystyle \|f\|_p = \left( \int_X |f(x)|^p \text{d}\mu(x) \right)^{1/p} < \infty$
