##### 矩阵范数
- 矩阵范数
	- **矩阵范数**是[[矩阵空间]]中的[[范数]], 它把[[矩阵]]映射到非负实数, 用来衡量矩阵的大小, 有多种矩阵范数, 但因为矩阵同时具有线性变换和向量两种身份, 所以矩阵范数主要分为[[算子范数]]与 F-范数. 算子范数刻画线性变换的最大放大能力, 由向量 p-范数诱导而来, 额外满足次可乘性 $||AB|| \leq ||A|| \cdot ||B||$. 而 F-范数相当于把矩阵拉平成一个长向量后取欧氏范数, 刻画整体能量
		- 1-范数, 最大列和, 矩阵所有列元素绝对值之和的最大值
			- $\displaystyle \|A\|_1 = \max_{\|x\|_1 = 1} \|Ax\|_1$
			- $\displaystyle||A||_1 = \max_{1 \leq j \leq n} \sum_{i=1}^{m} |a_{ij}|$
		- ∞-范数, 最大行和, 矩阵所有行元素绝对值之和的最大值
			- $\displaystyle \|A\|_\infty = \max_{\|x\|_\infty = 1} \|Ax\|_\infty$
			- $\displaystyle||A||_\infty = \max_{1 \leq i \leq m} \sum_{j=1}^{n} |a_{ij}|$
		- 2-范数, 谱范数, 矩阵的最大[[奇异值]]
			- $\displaystyle \|A\|_2 = \max_{\|x\|_2 = 1} \|Ax\|_2$
			- $\displaystyle \|A\|_2 = \sqrt{\lambda_{\max}(A^H A)} = \sigma_{\max}(A)$
			- $\displaystyle \|A\|_2 \le \sqrt{\|A\|_1 \|A\|_\infty}$
			- $\displaystyle \|A\|_2 \le \|A\|_F$
		- F-范数, 矩阵所有元素的平方和再开平方
			- $\displaystyle ||A||_F = \sqrt{\sum_{i=1}^{\min(m,n)} \sigma_i^2} = \sqrt{\sum_{i=1}^{m} \sum_{j=1}^{n} |a_{ij}|^2}$
			- $\displaystyle \|A\|_F = \sqrt{\text{tr}(A^T A)} = \sqrt{\text{tr}(A A^T)}$
