##### 矩阵函数
- 矩阵函数
	- **矩阵函数**是定义在[[矩阵空间|方阵空间]]上的[[映射|函数]], 记作 $f(A)$, 其中 $A \in \mathbb{F}^{n \times n}$, 将一个[[方阵]]映射为同阶方阵. 矩阵函数并非逐元素作用, 而是由矩阵的[[谱理论|谱结构]]完全决定. [[矩阵指数]], [[矩阵对数]]与[[矩阵三角函数]]是应用最广泛的矩阵函数. 在适当条件下, 矩阵函数可以通过多种等价形式定义, 主要包括[[幂级数|幂级数展开]], [[特征值分解]], [[若尔当分解]]和[[柯西积分公式]]等. 设标量函数 $f(z)$ 在原点邻域具有幂级数展开 $f(z) = \sum_{k=0}^{\infty} c_k z^k$, 收敛半径为 $R$, 若矩阵 $A$ 的[[谱半径]] $r(A) = \max_i |\lambda_i| < R$, 则可定义 $f(A) = \sum_{k=0}^{\infty} c_k A^k$. 若矩阵 $A$ 可对角化, 满足 $A = P D P^{-1}$, 其中 $D = \operatorname{diag}(\lambda_1, \dots, \lambda_n)$, 则可定义 $f(A) = P f(D) P^{-1}$. 若矩阵 $A$ 可若尔当化 $A = P J P^{-1}$, 其中 $J = \text{diag}(J_{k_1}(\lambda_1), \dots, J_{k_r}(\lambda_r))$, 则可定义 $f(A) = P f(J) P^{-1}$. 若标量函数 $f(z)$ 在简单闭曲线 $\Gamma$ 及其内部单值解析, 且 $A$ 的所有特征值均包含在 $\Gamma$ 内部, 则可通过预解算子定义矩阵函数 $f(A) = \frac{1}{2\pi i} \oint_{\Gamma} f(z)(zI - A)^{-1} \, \mathrm{d}z$
		- $f(A) = \sum_{k=0}^{\infty} c_k A^k = c_0 I_n + c_1 A + c_2 A^2 + c_3 A^3 + \dots$
		- $f(A) = P f(D) P^{-1}$, $f(D)=\mathrm{diag}(f(\lambda_1),\dots,f(\lambda_n))$
		- $f(A) = P f(J) P^{-1}$, $f(J) =\mathrm{diag}(f(J_{k_1}(\lambda_1)),\dots,f(J_{k_r}(\lambda_r)))$, $J_k(\lambda) = \lambda I_k + N$, $f(J_k(\lambda)) = \sum_{j=0}^{k-1} \frac{f^{(j)}(\lambda)}{j!} N^j$
		- $f(A) = \frac{1}{2\pi i} \oint_{\Gamma} f(z)(zI - A)^{-1} \, \mathrm{d}z$
