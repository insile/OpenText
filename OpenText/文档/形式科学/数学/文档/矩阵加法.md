##### 矩阵加法
- 矩阵加法
	- **矩阵加法**是指同型[[矩阵]]对应位置元素相加得到新同型矩阵的[[运算]]. 设 $A = (a_{ij})_{m \times n}$ 和 $B = (b_{ij})_{m \times n}$ 为 $\mathbb{F}^{m \times n}$ 中的两个同型矩阵, 则矩阵加法定义为 $A+B=(a_{ij}+b_{ij})_{m\times n}$
		- $(A+B)_{ij}=a_{ij}+b_{ij}$


>[!example]- 矩阵加法
> - $A + B = B + A$
> - $(A + B) + C = A + (B + C)$
> - $A + O = O + A = A$
> - $A + (-A) = O$
> - $k(A + B) = kA + kB$
> - $(k + m)A = kA + mA$
