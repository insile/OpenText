##### 上下极限
- 上下极限
	- **上下极限**是一种刻画对象收敛行为与长期振荡范围的工具, 可理解为随尺度缩小或索引增大时, 上下[[确界]]的极限. 上下极限相等当且仅当对象收敛. 该概念通常用于描述[[序列极限]]和[[函数极限]]. 对于实数序列是通过尾部子序列定义的, 对于函数序列是逐点定义的, 对于特定函数也可单独讨论自变量趋于某一点上下极限, 对于集合序列, 其定义建立在元素出现的频率上
		- 实数序列, 上下极限是该序列所有尾部子序列的上下确界所形成的单调序列的极限, 刻画了序列最终可能达到的最值
			- $\displaystyle \limsup _{n\to \infty }a_{n}=\lim_{n\to\infty}\sup\{a_k\mid k\geq n\}= \inf_{n \ge 1} \left( \sup_{k \ge n} a_k \right)$
			- $\displaystyle \liminf _{n\to \infty }a_{n}=\lim_{n\to\infty}\inf\{a_k\mid k\geq n\}= \sup_{n \ge 1} \left( \inf_{k \ge n} a_k \right)$
		- 函数, 在某点的上下极限, 就是当自变量无限逼近该点时, 函数值在任意小邻域内最终所能达到的可能最值, 函数序列可逐点定义
			- $\displaystyle \limsup_{x \to x_0} f(x) = \lim_{\delta \to 0^+} \sup \{ f(x) \mid 0 < |x - x_0| < \delta, x \in E \}$
			- $\displaystyle \liminf_{x \to x_0} f(x) = \lim_{\delta \to 0^+} \inf \{ f(x) \mid 0 < |x - x_0| < \delta, x \in E \}$
		- 集合序列, 上极限由无限常出现的元素组成, 先考虑从 $n$ 开始的集合并集 $\bigcup^{\infty}_{k=n}A_{k}$, 然后求所有这些并集的交集. 下极限由最终总是出现的元素组成, 先考虑从 $n$ 开始的集合交集 $\bigcap^{\infty}_{k=n}A_{k}$, 然后求所有这些交集的并集
			- $\displaystyle \limsup _{n\to \infty }A_{n}=\bigcap^{\infty}_{n=1}\bigcup^{\infty}_{k=n}A_{k}$
			- $\displaystyle \liminf _{n\to \infty }A_{n}=\bigcup^{\infty}_{n=1}\bigcap^{\infty}_{k=n}A_{k}$
