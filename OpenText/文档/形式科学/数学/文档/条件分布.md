##### 条件分布
- 条件分布
	- **条件分布**是[[随机向量]]的[[概率分布]], 是[[联合分布]]在给定条件下的重新归一化, 用于描述已知部分[[随机变量]]取值时, 其余随机变量的概率规律. 随机变量相互独立, 当且仅当其条件分布等于对应的[[边缘分布]]. 条件分布可通过[[累积分布函数|条件累积分布函数]]统一描述, 对于离散型随机变量和连续型随机变量又有[[离散型随机变量|条件质量]]与[[连续型随机变量|条件密度]]. [[随机事件]]的条件概率就是条件分布在某一具体事件上的取值, [[条件期望]]是条件分布的平均值. 设 $\mathbf{X} = (X_1, X_2)$ 为概率空间 $(\Omega, \mathcal{F}, P)$ 上的二维随机向量, 取值为 $\mathbf{x} = (x_1, x_2) \in \mathbb{R}^2$, 条件分布描述的是在已知 $X_2 = x_2$ 的情况下, $X_1$ 的分布情况, 记作 $F_{X_1 \mid X_2}(x_1 \mid x_2) = P(X_1 \le x_1 \mid X_2 = x_2)$. 当 $P(X_2 = x_2) > 0$ 时, 可以直接利用条件概率经典公式定义, 当 $P(X_2 = x_2) = 0$ 时, 需要通过条件密度积分. 若 $\mathbf{X}$ 为离散型随机向量, $p_{\mathbf{X}}(x_1, x_2)$ 为联合质量, $p_{X_2}(x_2)$ 为 $X_2$ 的边缘质量, 则对任意满足 $p_{X_2}(x_2) > 0$ 的 $x_2$, 给定 $X_2 = x_2$ 条件下 $X_1$ 的条件质量定义为 $p_{X_1 \mid X_2}(x_1 \mid x_2)$. 若 $\mathbf{X}$ 为连续型随机向量, $f_{\mathbf{X}}(x_1, x_2)$ 为联合密度, $f_{X_2}(x_2)$ 为 $X_2$ 的边缘密度, 则对任意满足 $f_{X_2}(x_2) > 0$ 的 $x_2$, 给定 $X_2 = x_2$ 条件下 $X_1$ 的条件密度定义为 $f_{X_1 \mid X_2}(x_1 \mid x_2)$
		- $F_{X_1 \mid X_2}(x_1 \mid x_2) = P(X_1 \le x_1 \mid X_2 = x_2)$
		- $\displaystyle p_{X_1 \mid X_2}(x_1 \mid x_2) = \frac{p_{\mathbf{X}}(x_1, x_2)}{p_{X_2}(x_2)}$
		- $\displaystyle f_{X_1 \mid X_2}(x_1 \mid x_2) = \frac{f_{\mathbf{X}}(x_1, x_2)}{f_{X_2}(x_2)}$
		- $\displaystyle F_{X_1 \mid X_2}(x_1 \mid x_2) = \sum_{u_1 \le x_1} p_{X_1 \mid X_2}(u_1 \mid x_2)$
		- $\displaystyle F_{X_1 \mid X_2}(x_1 \mid x_2) = \int_{-\infty}^{x_1} f_{X_1 \mid X_2}(u_1 \mid x_2) \, \mathrm{d}u_1$
