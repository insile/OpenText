##### 傅里叶级数
- 傅里叶级数
	- **傅里叶级数**是一种[[函数项级数]], 旨在将[[周期函数]]表示为[[三角函数]]的无限[[线性组合]]. 借助[[欧拉公式]], 三角函数形式的傅里叶级数可进一步简化为[[指数函数|复指数函数]]形式. 设 $f(x)$ 是一个以 $T$ 为周期的函数, 并且 $f(x)$ 在周期 $T$ 内满足适当的可积或正则条件, 则 $f(x)$ 可以在[[正交基]] $\{ 1, \cos(n\omega_0 x), \sin(n\omega_0 x) \mid n \in \mathbb{Z}^+ \}$ 或 $\{e^{i n \omega_0 x} \mid n \in \mathbb{Z}\}$ 上进行[[傅里叶展开]], 其中, $\omega_0 = \frac{2\pi}{T}$ 为角频率, 而傅里叶系数由函数在正交基上的[[正交投影]]给出, 这是最直观的均方收敛形式. 除此之外, 傅里叶级数还有多种[[傅里叶级数收敛性|收敛形式]], 其性质可以通过[[傅里叶级数部分和|部分和]]来分析. 傅里叶级数在[[希尔伯特空间]]上推广为[[广义傅里叶级数]], 即通过空间内任意完备正交基来展开函数. 傅里叶级数在非周期函数上推广为[[傅里叶变换]], 即通过周期趋于无穷将离散频率扩展为连续频谱
		- $\displaystyle f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos \left( \frac{2\pi n x}{T} \right) + b_n \sin \left( \frac{2\pi n x}{T} \right) \right)$
			- $\displaystyle a_n = \frac{2}{T} \int_{0}^{T} f(x)\cos\left(\frac{2\pi n x}{T}\right)\mathrm{d}x$
			- $\displaystyle b_n = \frac{2}{T} \int_{0}^{T} f(x)\sin\left(\frac{2\pi n x}{T}\right)\mathrm{d}x$
			- $\displaystyle a_0 = \frac{2}{T} \int_{0}^{T} f(x)\mathrm{d}x$
		- $\displaystyle f(x) \sim \sum_{n=-\infty}^{\infty} c_n e^{i \frac{2\pi n x}{T}}$
			- $\displaystyle c_n = \frac{1}{T} \int_0^T f(x) e^{-i \frac{2\pi n x}{T}} \mathrm{d}x$


>[!example]- 傅里叶级数
> - 方波 $f(x) = \begin{cases} 1, & 0 < x < \pi \\ -1, & -\pi < x < 0 \end{cases}$
> 	- $\displaystyle f(x)=\frac{4}{\pi} \sum_{k=0}^{\infty} \frac{1}{2k+1}\sin\big((2k+1)x\big)$
> - 三角波 $f(x) = |x|$, $x \in [-\pi, \pi]$
> 	- $\displaystyle f(x)=\frac{\pi}{2} -\frac{4}{\pi} \sum_{k=0}^{\infty} \frac{\cos\big((2k+1)x\big)}{(2k+1)^2}$
> - 锯齿波 $f(x) = x$, $x \in (-\pi, \pi)$
> 	- $\displaystyle f(x)=2 \sum_{n=1}^{\infty} \frac{(-1)^{\,n+1}}{n}\sin(nx)$
