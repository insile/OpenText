##### 线性组合
- 线性组合
	- **线性组合**是指对给定的一个[[向量组]]进行向量加法和标量乘法运算得到新向量. 设 $V$ 是域 $\mathbb{F}$ 上的[[向量空间]], $\mathbf{a}_1,\mathbf{a}_2,\dots,\mathbf{a}_n \in V$ 为有限个向量, 若存在标量 $k_1,k_2,\dots,k_n \in \mathbb{F}$, 使得 $\mathbf{b} = k_1\mathbf{a}_1 + k_2\mathbf{a}_2 + \cdots + k_n\mathbf{a}_n$, 则称向量 $\mathbf{b}$ 是向量组 $(\mathbf{a}_1,\mathbf{a}_2,\dots,\mathbf{a}_n)$ 的一个线性组合或者说向量 $\mathbf{b}$ 可由向量组线性表示, 其中 $k_1,k_2,\dots,k_n$​ 称为该线性组合的系数. 任何向量组都可以通过全零系数 $k_i=0$ 组合出零向量 $\mathbf{0}$. 向量空间对线性组合封闭, 而[[线性变换]] $T$ 保持线性组合. 向量组的所有线性组合构成该向量组的[[张成空间]]. 线性组合可以用于[[线性方程组等价形式|表示]]线性方程组. 线性组合可推广为[[仿射组合]], [[凸组合]], [[锥组合]], 它们对系数施加了不同的约束
		- $\displaystyle\sum^{n}_{i=1}k_i\mathbf{a}_i=k_1\mathbf{a}_1+k_2\mathbf{a}_2+\cdots+k_n\mathbf{a}_n=\mathbf{b}$
		- $T(\displaystyle\sum^{n}_{i=1}k_i\mathbf{a}_i)=\displaystyle\sum^{n}_{i=1}k_i T(\mathbf{a}_i)$
		- $T(k_1\mathbf{a}_1 + k_2\mathbf{a}_2 + \cdots + k_n\mathbf{a}_n) = k_1T(\mathbf{a}_1) + k_2T(\mathbf{a}_2) + \cdots + k_nT(\mathbf{a}_n)$


>[!example]- 线性组合
> - $\mathbf{a_1} = (1, 2)$, $\mathbf{a_2} = (3, 4)$
> 	- $2\mathbf{a_1} - \mathbf{a_2} = (-1, 0)$
> - $\mathbf{a_1} = (1, 2)$, $\mathbf{a_2} = (2, 4)$
> 	- $2\mathbf{a_1} + \mathbf{a_2} = (4, 8)$
> - $\mathbf{a}_1 = (1, 0, 0)$, $\mathbf{a}_2 = (0, 1, 0)$, $\mathbf{a}_3 = (0, 0, 1)$
> 	- $\mathbf{a}_1+\mathbf{a}_2+\mathbf{a}_3=(1,1,1)$
> - $\mathbf{a}_1 = (1, 2, 3)$, $\mathbf{a}_2 = (2, 4, 6)$, $\mathbf{a}_3 = (-1, 1, 0)$
> 	- $\mathbf{a}_1+\mathbf{a}_2+\mathbf{a}_3=(2,7,9)$
