##### 微分方程
- 微分方程
	- **微分方程**是包含[[映射|未知函数]]及其[[微积分|导数]]的[[方程]], 它通过导数规定了函数的变化规律, 可以看作是对函数的一种约束条件. 具体来说, 如果一个方程由自变量 $x$, 未知函数 $y$ 以及 $y$ 的各阶导数 $y', y'', \dots, y^{(n)}$ 构成, 那么这个方程就称为微分方程, 可记作 $F=0$. 微分方程的阶数是方程中导数的最高阶 $n$, 而微分方程的解是使方程成为恒等式 $F\equiv0$ 的函数 $y = \varphi(x)$, 求解微分方程就是找到所有满足方程变化约束的函数. 根据自变量的个数, 微分方程可分为[[常微分方程]]和[[偏微分方程]]. 根据未知函数及其导数的形式, 又可分为线性和非线性微分方程. 根据阶数的不同, 还可分为一阶, 二阶以及高阶微分方程. 此外, 多个微分方程可构成微分方程组, 用于刻画多个未知函数及其导数之间相互作用, 共同演化的过程
		- $F(x,y,y',y'',\dots,y^{(n)})=0$


>[!example]- 微分方程
>- $\displaystyle\frac{dy}{dx} = y$, 函数 $y$ 的斜率等于当前 $y$ 的值本身
>	- 分离变量 $\displaystyle\frac{1}{y}\text{d}y = \text{d}x$ 
>	- 两边积分 $\displaystyle \int \frac{1}{y} \mathrm{d}y = \int 1 \mathrm{d}x \Rightarrow \ln |y| = x + C \Rightarrow |y|=e^{x + C}=e^C\cdot e^x$
>	- 解得 $\displaystyle y = C' e^x$, 其中 $C'=e^C$ 是常数
>	- [[自然常数]] $e$ 是微分方程 $y'=y$, 初值 $y(0)=1$ 的解在 $x=1$ 处的函数值
> - $\displaystyle\frac{dy}{dx} = xy$, 函数 $y$ 的斜率等于 $x$ 与当前 $y$ 的乘积
> 	- 分离变量 $\displaystyle\frac{1}{y}\text{d}y = x\text{d}x$ 
> 	- 两边积分 $\displaystyle\int\frac{1}{y}\text{d}y = \int x\text{d}x \Rightarrow \displaystyle \ln|y| = \frac{x^2}{2} + C\Rightarrow |y|=e^{\frac{x^2}{2} + C}=e^C\cdot e^{\frac{x^2}{2}}$ 
> 	- 解得 $\displaystyle y = C' e^{\frac{x^2}{2}}$, 其中 $C'=e^C$ 是常数
> - $\displaystyle\frac{dy}{dx} = x - y$, 函数 $y$ 的斜率等于 $x$ 减去当前 $y$ 值
> 	- 积分因子 $\displaystyle \mu(x) = e^{\int p(x) \mathrm{d}x} = e^{\int 1 \mathrm{d}x} = e^x$
> 	- 同乘积分因子 $\displaystyle e^x \frac{\mathrm{d}y}{\mathrm{d}x} + e^x y = e^x x \Rightarrow \frac{\mathrm{d}}{\mathrm{d}x} (y e^x) = x e^x$
> 	- 两边积分 $\displaystyle \int \frac{\mathrm{d}}{\mathrm{d}x} (y e^x) \mathrm{d}x = \int x e^x \mathrm{d}x$, 其中 $\displaystyle \int x e^x \mathrm{d}x = x e^x - e^x$
> 	- 解得 $\displaystyle y e^x = x e^x - e^x + C \Rightarrow y = x - 1 + C e^{-x}$, 其中 $C$ 是常数
