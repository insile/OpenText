##### 整数进制
- 整数进制
	- **整数进制**是用指定基数的幂次累加来表示[[整数]]的方式, 本质上是通过反复使用整数的[[整除|带余除法]]来实现. 常见的进制包括[[二进制]], [[八进制]], [[十进制]], [[十六进制]]等, 可以进行[[进制转换]]. 设 $b$ 是一个大于 $1$ 的整数, 称为基数, 那么对于任意给定的正整数 $x$, 存在且仅存在一组非负整数 $k$ 以及系数 $a_0, a_1, \dots, a_k$, 使得 $x = a_k b^k + a_{k-1} b^{k-1} + \dots + a_1 b + a_0$, 其中, 最高位系数不为零 $0 < a_k < b$, 其余各位系数满足 $0 \le a_i < b$. 这个多项式形式通常简记为位置记数法 $x = (a_k a_{k-1} \dots a_1 a_0)_b$
		- $x = a_k b^k + a_{k-1} b^{k-1} + \dots + a_1 b + a_0$
