##### 整数进制
- 整数进制
	- **整数进制**是用指定基数的幂次累加来表示[[整数]]的方式, 本质上是通过反复使用整数的[[整除|带余除法]]来实现. 常见的进制包括[[二进制]], [[八进制]], [[十进制]], [[十六进制]]等, 不同进制之间可以进行[[进制转换]]. 设 $b$ 是一个大于 $1$ 的整数, 称为基数, 那么对于任意给定的正整数 $x$, 存在且仅存在一组非负整数 $k$ 以及系数 $a_0, a_1, \dots, a_k$, 使得 $x = \sum_{i=0}^{k} a_i b^i$, 其中, 最高位系数不为零 $0 < a_k < b$, 其余各位系数满足 $0 \le a_i < b$. 这个多项式形式通常简记为位置记数法 $x = (a_k a_{k-1} \dots a_1 a_0)_b$. 对于任意[[实数]] $x$, 其进制表示可以推广为包含整数部分和[[小数]]部分的收敛[[序列级数|无限级数]] $x=\pm\sum_{i=-\infty}^{k}a_ib^i$, 用一个基数点将整数部分和小数部分隔开, 记作 $x=\pm(a_ka_{k-1}\cdots a_1a_0.a_{-1}a_{-2}\cdots)_b$. 任意实数的进制展开并非总是唯一, 并且不是所有实数都能用有限位数的 $b$ 进制小数精确表示. 对于任意整数基数 $b > 1$, 一个[[互素|最简]][[有理数|分数]] $\frac{p}{q}$ 能够用有限位 $b$ 进制小数精确表示, 当且仅当分母 $q$ 的所有素因数都整除基数 $b$, 即 $q \mid b^n$
		- $\displaystyle x = \sum_{i=0}^{k} a_i b^i = a_k b^k + a_{k-1} b^{k-1} + \dots + a_1 b + a_0$
		- $\displaystyle x=\pm\sum_{i=-\infty}^{k}a_ib^i = a_k b^k + \dots + a_1 b^1 + a_0 b^0 + a_{-1} b^{-1} + a_{-2} b^{-2} + \dots$
