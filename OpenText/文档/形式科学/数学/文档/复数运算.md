##### 复数运算
- 复数运算
	- **复数运算**是指[[复数]]的[[运算]], 基于[[实数]]和[[虚数|虚数单位]]定义, 复数通过虚数单位实现代数封闭. 设复数集 $\mathbb{C}=\{ a+bi \mid a,b\in\mathbb{R},i^2=-1\}$, 则复数运算主要包括[[加法]], [[减法]], [[乘法]], [[除法]], [[指数运算]], [[开方运算]], [[对数运算]], 并且运算在[[复平面]]上具有几何意义
		- 加法, 设 $z_1 = a + bi,z_2 = c + di\in\mathbb{C}$, $a,b,c,d\in\mathbb{R}$, 定义 $z_1+z_2=(a+c)+(b+d)i$, 逆元为 $-z_1=-a-bi$
		- 乘法, 设 $z_1 = a + bi,z_2 = c + di\in\mathbb{C}$, $a,b,c,d\in\mathbb{R}$, 定义 $z_1\times z_2=(ac-bd)+(ad+bc)i$, 逆元为 $z_1^{-1}=\frac{a-bi}{a^2+b^2}$
		- 减法, 设 $z_1 = a + bi,z_2 = c + di\in\mathbb{C}$, $a,b,c,d\in\mathbb{R}$, 定义 $z_1-z_2=z_1+(-z_2)= (a - c) + (b - d)i$
		- 除法, 设 $z_1 = a + bi,z_2 = c + di\in\mathbb{C}$, $a,b,c,d\in\mathbb{R}$, 定义 $\frac{z_1}{z_2}=z_1z_2^{-1}=\frac{ac + bd}{c^2 + d^2} + \frac{bc - ad}{c^2 + d^2}i$
		- 指数, 设 $z=a+bi\in\mathbb{C}$, 定义 $e^z=e^{a+bi} = e^a (\cos b + i \sin b)$
		- 开方, 设 $z=re^{i\theta}\in\mathbb{C}$, 定义 $z^{\frac{1}{n}} = \sqrt[n]{r} \left[ \cos\left(\frac{\theta + 2k\pi}{n}\right) + i \sin\left(\frac{\theta + 2k\pi}{n}\right) \right]$, $k = 0, 1, \dots, n-1$
		- 对数, 设 $z=re^{i\theta}\in\mathbb{C}$, 定义 $\ln z = \ln r + i(\theta + 2k\pi)$, $k \in \mathbb{Z}$
