##### 正交特征值分解
- 正交特征值分解
	- **正交特征值分解**是一种[[矩阵因式分解]], 记作 $A = Q \Lambda Q^T$ 或 $A = U \Lambda U^H$, 指[[方阵]] $A$ 分解为[[对角矩阵]] $\Lambda$ 以及[[正交矩阵]] $Q$ 或[[酉矩阵]] $U$. 正交特征值分解是[[可正交对角化矩阵]]的因式分解形式, 也是有限维[[可正交对角化算子|线性算子]]的[[谱分解]]. 对角矩阵 $\Lambda$ 以[[特征值和特征向量|特征值]]为对角线元素 $\Lambda=\text{diag}(\lambda_1,\dots,\lambda_n)$, 正交矩阵 $Q$ 或酉矩阵 $U$ 以[[特征值和特征向量|特征向量]] $\{\mathbf{a}_1, \dots, \mathbf{a}_n\}$ 为列向量, 可构成标准正交基. 进一步, 该分解可以改写为谱展开, 即将方阵 $A$ 分解为一族[[正交投影矩阵]] $P_i$ 作用的叠加, 每个一维投影 $P_i$ 将向量投影到特征值 $\lambda_i$ 对应的[[特征空间|特征子空间]]上
		- $\displaystyle A = Q \Lambda Q^T =\lambda_1\mathbf{a}_1\mathbf{a}_1^T+\lambda_2\mathbf{a}_2\mathbf{a}_2^T+\cdots+\lambda_n\mathbf{a}_n\mathbf{a}_n^T=\sum^{n}_{i=1}\lambda_i\mathbf{a}_i\mathbf{a}_i^T$
		- $A = Q \Lambda Q^T =\begin{bmatrix} \mathbf{a}_1&\cdots&\mathbf{a}_n\end{bmatrix}\begin{bmatrix} \lambda_1& &\\&\ddots &\\& &\lambda_n\end{bmatrix}\begin{bmatrix} \mathbf{a}_1^T\\\vdots\\\mathbf{a}_n^T\end{bmatrix}$
		- $\displaystyle A = \lambda_1 P_1 + \lambda_2 P_2 + \dots + \lambda_n P_n = \sum_{i=1}^n \lambda_i P_i$, $P_i = \mathbf{a}_i \mathbf{a}_i^T$
		- $P_i^2 = P_i$, $P_i^T = P_i$, $P_i P_j = 0$, $\sum_{i=1}^n P_i = I$


>[!example]- 正交特征值分解
>- 特征值分解
>	- $\begin{bmatrix}4&1\\2&3\end{bmatrix} = \begin{bmatrix}-\frac{1}{2}&1\\1&1\end{bmatrix} \begin{bmatrix}2&0\\0&5\end{bmatrix} \begin{bmatrix}-\frac{2}{3}&\frac{2}{3}\\\frac{2}{3}&\frac{1}{3}\end{bmatrix}$
>	- $\lambda_1=2$, $\mathbf{v}_1=(-\frac{1}{2},1)$
>	- $\lambda_2=5$, $\mathbf{v}_2=(1,1)$
>- 正交特征值分解
>	- $\begin{bmatrix}2&1\\1&2\end{bmatrix}=\begin{bmatrix}-\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\end{bmatrix}\begin{bmatrix}1&0\\0&3\end{bmatrix}\begin{bmatrix}-\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}&\frac{1}{\sqrt{2}}\end{bmatrix}$
>	- $\begin{bmatrix}2&1\\1&2\end{bmatrix}=1\begin{bmatrix}-\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}\end{bmatrix}\begin{bmatrix}-\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}\end{bmatrix}^T+3\begin{bmatrix}\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}\end{bmatrix}\begin{bmatrix}\frac{1}{\sqrt{2}}\\\frac{1}{\sqrt{2}}\end{bmatrix}^T$
>	- $\lambda_1=1$, $\mathbf{v}_1=(-1,1)$
>	- $\lambda_2=3$, $\mathbf{v}_2=(1,1)$
