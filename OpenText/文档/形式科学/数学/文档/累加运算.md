##### 累加运算
- 累加运算
	- **累加运算**是对[[序列]]元素按顺序依次相加求和的[[运算]]. 设 $\{a_i\}$ 是定义在某个加法结构上的序列, 则从第 $m$ 项依次相加到第 $n$ 项称为累加运算, 记作 $\sum^{n}_{i=m}a_i$, 其中, $\sum$ 为累加符号, 表示执行累加操作, $i$ 为累加索引, 表示当前项位置, $m, n\in\mathbb{Z}$, $m \leq n$ 分别表示累加索引的下限和上限, $a_i$ 表示索引 $i$ 对应的元素. 累加运算满足多种运算性质, 可以推广到多种形式, 包括多重求和, 带权求和, 无穷求和以及更一般的索引集合求和等
		- $\displaystyle \sum_{i=m}^{n} a_i = a_m + a_{m+1} + \cdots + a_n$


>[!example]- 累加运算
> - $\displaystyle \sum_{i=m}^n (a_i \pm b_i) = \sum_{i=m}^n a_i \pm \sum_{i=m}^n b_i$
> - $\displaystyle \sum_{i=m}^n c a_i = c \sum_{i=m}^n a_i$
> - $\displaystyle \sum_{i=m}^n a_i = \sum_{i=m}^k a_i + \sum_{i=k+1}^n a_i$, $m \le k < n$
> - $\displaystyle \sum_{i=m}^n \sum_{j=p}^q a_{i,j} = \sum_{j=p}^q \sum_{i=m}^n a_{i,j}$
