##### 向量
- 向量
	- **向量**是指[[向量空间]]的元素, 也就是说, 任意满足向量运算公理的对象都可称为向量, 是既有大小又有方向的[[几何向量]]在代数公理化下的抽象推广. 设 $\mathbb{F}$ 为一个域, 通常取 $\mathbb R$ 或 $\mathbb C$, 则向量空间 $V$ 是配备加法 $+:V\times V\to V$ 与数乘 $\cdot:\mathbb F\times V\to V$ 两种运算的集合, 对任意 $\mathbf{a},\mathbf{b},\mathbf{c}\in V$, $m,n\in \mathbb{F}$ 满足以下运算律. $V$ 中的元素称为向量, 而 $\mathbb F$ 中的元素相对地称为标量. 向量最基本的性质源自这些公理的直接推论, 通常以[[向量组]]的形式讨论. 若 $V$ 是[[向量空间的维数|有限维向量空间]], 则可以选定一组[[向量空间的基|基]], 使得每个向量都可以唯一地表示为基向量的[[线性组合]], 系数称为[[坐标向量|向量坐标]], 可用[[向量矩阵]]存储, 表现为列向量或行向量, 这使得抽象向量空间 $V$ 与最直观的坐标向量空间 $\mathbb F^n$ 建立[[向量空间的同构|同构]], 此时, 向量运算在坐标表示下表现为逐分量运算. 相反, 若 $V$ 是无限维向量空间, 则其向量行为更加复杂, 需要严格区分代数意义下的哈默尔基与分析意义下的绍德尔基. 在具体模型中, 向量可表现为[[序列]]或[[实函数|函数]], 例如, 实数序列与实函数. 此外, 向量还可以通过[[范数]], [[度量]], [[内积]]等概念引入长度, 距离与角度等几何结构
		- 加法封闭性, $\mathbf{a}+\mathbf{b}\in V$
		- 加法交换律, $\mathbf{a} + \mathbf{b} = \mathbf{b} + \mathbf{a}$
		- 加法结合律, $\mathbf{a} + (\mathbf{b} + \mathbf{c}) = (\mathbf{a} + \mathbf{b}) + \mathbf{c}$
		- 加法单位元, 存在零向量 $\mathbf{0}$, $\mathbf{a} + \mathbf{0} = \mathbf{a}$
		- 加法逆元, 存在负向量 $-\mathbf{a}$, $\mathbf{a} + (-\mathbf{a}) = \mathbf{0}$
		- 数乘封闭性, $m\mathbf{a}\in V$
		- 数乘对向量的分配律, $m(\mathbf{a} + \mathbf{b}) = m\mathbf{a} + m\mathbf{b}$
		- 数乘对标量的分配律, $(m + n)\mathbf{a} = m\mathbf{a} + n\mathbf{a}$
		- 数乘结合律, $m(n\mathbf{a}) = (mn)\mathbf{a}$
		- 数乘单位元, 存在单位标量 $1$, $1\mathbf{a} = \mathbf{a}$


> [!example]- 向量
> - 有限维坐标空间 $\mathbb{R}^3$, 哈默尔基为标准正交基 $\{e_1,e_2,e_3\}$, 任意向量可唯一表示为基向量的有限线性组合
> 	- $\mathbf{a} = (1,2,3) = 1e_1 + 2e_2 + 3e_3 \in \mathbb{R}^3$
> - 有限支撑序列空间 $c_{00} = \bigoplus_{n=1}^{\infty} \mathbb{R}$, 哈默尔基为 $\{e_n\}_{n=1}^{\infty}$, 该空间中的每个向量只有有限个非零分量, 因此每个向量都是基向量的有限线性组合, 这是哈默尔基意义下的可数维空间
> 	- $\mathbf{a} = (1, 2, 3, 0, 0, \dots) = e_1 + 2e_2 + 3e_3 \in c_{00}$
> - 平方可和序列空间 $\ell^2$, 标准正交基 $\{e_n\}_{n=1}^{\infty}$ 为绍德尔基, 向量可表示为无穷级数. 这是绍德尔基意义下的展开, 收敛是范数收敛, $\ell^2$ 作为巴拿赫空间的哈默尔维数实际为连续统 $\mathfrak{c}$, 但它的绍德尔维数是可数的
> 	- $\mathbf{a} = (1, \tfrac12, \tfrac13, \dots) = \sum_{n=1}^{\infty} \frac{1}{n} e_n \in \ell^2$
> - 平方可积函数空间 $L^2([-1,1])$, 三角函数系或多项式系为绍德尔基. 函数是向量, 因为它属于一个配备了加法和数乘的向量空间, 可用可数正交基的无穷级数表示, 例如可取勒让德多项式系 $\{P_n\}$
> 	- $f(x) = x^2 = \frac13 P_0(x) + \frac23 P_2(x) \in L^2([-1,1])$
> - 全体实函数空间, $\mathbb{R}^{[0,1]}$, 如果把所有实值函数作为一个向量空间, 它的哈默尔维数严格大于可数, 等于 $2^{2^{\aleph_0}}$, 远超连续统, 此时不存在可数的展开基, 向量只能作为原始的映射本身来处理 $f: [0,1] \to \mathbb{R}$
> 	- $f(x) = x^2 \in \mathbb{R}^{[0,1]}$
