##### 齐次多项式
- 齐次多项式
	- **齐次多项式**是指[[单项式|每一项]]次数都相同的[[多项式]]. 设 $p(x_1,\dots,x_n)$ 是一个多元多项式, 如果其中每一项的所有变量的次数之和都相同 $\alpha_1 + \dots + \alpha_n = k$, 则称 $p$ 为 $k$ 次齐次多项式. 此外, 多项式 $p(x_1,\dots,x_n)$ 是 $k$ 次齐次多项式的充要条件是, 对于任意系数 $\lambda$, 均满足缩放性质 $p(\lambda x_1, \dots, \lambda x_n) = \lambda^k p(x_1, \dots, x_n)$, 也就是说对所有变量同时进行相同比例缩放时, 表达式按固定的 $k$ 次幂变化, 这是齐次多项式最本质的特征. 一次齐次多项式称为[[线性泛函|线性型]], 二次齐次多项式称为[[二次型]], 三次齐次多项式称为三次型. 齐次多项式与普通非齐次多项式之间可以通过引入或抹去辅助变量进行转换, 称为齐次化与去齐次化. 齐次多项式可诱导齐次函数与[[多项式方程|齐次方程]]. 齐次多项式方程的解集在几何上构成一个以原点为顶点的锥
		- $\displaystyle p(x_1, \dots, x_n) = \sum_{|\alpha| = k} c_\alpha x_1^{\alpha_1}x_2^{\alpha_2}\dots x_n^{\alpha_n}$, $|\alpha| = \alpha_1 + \alpha_2 + \dots + \alpha_n = k$
