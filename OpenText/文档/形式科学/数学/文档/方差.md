##### 方差
- 方差
	- **方差**是指[[概率分布]]的离散程度, 是[[随机变量]]围绕[[期望]]的平均平方离差. 方差存在比期望存在更强, 本质上是随机变量的[[矩|二阶中心矩]]. 设 $X$ 为概率空间 $(\Omega, \mathcal{F}, P)$ 上的随机变量, 其期望为 $\mathrm{E}[X]$, 若 $X$ 平方可积, 即 $\mathrm{E}[X^2] < \infty$, 则 $X$ 的方差定义为偏离均值平方的期望 $\mathrm{Var}(X) = \mathrm{E}[(X - \mathrm{E}[X])^2]$. 方差的算术平方根 $\sigma_X = \sqrt{\mathrm{Var}(X)}$​ 称为[[标准差]], 与 $X$ 同量纲, 更便于实际解释. 方差满足非负性和退化性, 对线性变换满足平移不变性与尺度平方性, 对独立随机变量满足可加性. [[协方差]]是方差的双变量推广, 而方差是协方差在两变量相同时的特例
		- $\mathrm{Var}(X) = \mathrm{E}[(X - \mathrm{E}[X])^2]= \mathrm{E}[X^2] - (\mathrm{E}[X])^2$
		- 非负性, $\mathrm{Var}(X) \ge 0$
		- 退化性, $\mathrm{Var}(X) = 0 \iff P(X = c) = 1$
		- 平移不变性, $\mathrm{Var}(X + b) = \mathrm{Var}(X)$
		- 尺度平方性, $\mathrm{Var}(aX) = a^2 \mathrm{Var}(X)$
		- 和的方差, $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) + 2\mathrm{Cov}(X, Y)$
		- 独立可加性, $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$, $X,Y\text{ 独立}$
		- 协方差退化, $\mathrm{Var}(X) = \mathrm{Cov}(X, X)$
