##### 可和序列空间
- 可和序列空间
	- **可和序列空间**是由所有 $p$ 次幂[[序列级数|可和]]的序列构成的[[函数空间]], 记作 $l^p$, 配备[[求和范数]] $\|\cdot\|$ 构成[[赋范向量空间]]. 对于 $1 \le p < \infty$, 其标准范数为 $\|\mathbf{x}\|_p = \left( \sum_{i=1}^{\infty} |x_i|^p \right)^{1/p}$, 对于 $p = \infty$, 其标准范数为 $\|\mathbf{x}\|_\infty = \sup_{i} |x_i|$. 而 $l^p$ 空间在上述范数下均为[[巴拿赫空间]]. 特别地, 当 $p = 2$ 时, $l^2$ 空间是[[希尔伯特空间]], 配备[[内积]] $\langle \cdot,\cdot \rangle$, 定义为序列元素乘积累加. 设 $1 < p < \infty$, 若 $\frac{1}{p} + \frac{1}{q} = 1$, 则称 $p$ 与 $q$ 为共轭指数, 并且 $l^p$ 空间的[[对偶空间]] $(l^p)^*$ 与 $l^q$ 空间是[[等距映射|等距同构]]的 $(l^p)^* \cong l^q$. 当 $p=2$ 时, 共轭指数 $q=2$, 这说明 $l^2$ 是自对偶的
		- $\displaystyle l^p = \left\{\{x_i\}_{i=1}^{\infty}\subset \mathbb{C} \mid \sum_{i=1}^{\infty} |x_i|^p < \infty \right\}$
		- $\displaystyle \|\mathbf{x}\|_p = \left( \sum_{i=1}^{\infty} |x_i|^p \right)^{1/p} < \infty$
