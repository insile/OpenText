##### 随机变量运算
- 随机变量运算
	- **随机变量运算**是对[[随机变量]]进行的[[运算]]和[[运算律]], 多个随机变量通过基本运算可以构造一个新的随机变量, 并且拥有新的[[概率分布]]和[[期望]], 本质上是定义在[[样本空间]]上的[[函数运算]], 主要包括随机变量的加法和乘法. 其中, 加法用于描述累积效应, 乘法用于刻画相互作用或放大效应. 设独立随机变量 $X$ 和 $Y$, 则 $Z = X + Y$ 的和分布是 $X$ 和 $Y$ 的[[卷积]] $f_{X+Y} = f_X * f_Y$, 而 $Z = XY$ 的积分布通常更复杂. 和分布的期望只要各自期望存在, 不需要独立性, 而积分布的期望交换需要独立变量
		- $Z = X + Y$
			- $\displaystyle f_Z(z) = \int_{-\infty}^{\infty} f_X(x) f_Y(z-x) \mathrm{d}x$
			- $\mathrm{E}[X + Y] = \mathrm{E}[X] + \mathrm{E}[Y]$
		- $Z = XY$
			- $\displaystyle f_{Z}(z)=\int _{-\infty }^{\infty }f_{X}(x)f_{Y}(z/x){\frac {1}{|x|}}\mathrm{d}x$
			- $\mathrm{E}(XY) = \mathrm{E}(X)\mathrm{E}(Y)$, $X$, $Y$ 独立
