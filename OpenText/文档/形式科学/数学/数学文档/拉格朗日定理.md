##### 拉格朗日定理
- 拉格朗日定理
	- **拉格朗日定理**描述了一个[[有限群]]和它的[[子群]]的元素个数之间的关系. 设 $G$ 是有限群, $H$ 是其子群, 则 $|H|$ [[整除]] $|G|$, 而且 $\frac{|G|}{|H|}$ 是[[陪集|子群指数]]
		- $|G| = [G : H] \cdot |H|$
		- $\displaystyle\frac{|G|}{|H|} = [G : H]$


>[!example]- 拉格朗日定理
>- 群
>	- $G = \mathbb{Z}_6 = \{0, 1, 2, 3, 4, 5\}$, 在模 $6$ 加法下构成一个有限群, 阶 $|G| = 6$
>- 子群 
>	- $H = \{0, 3\}$, 是 $\mathbb{Z}_6$ ​ 中由 $3$ 生成的子群, 阶 $|H| = 2$ 
>- 拉格朗日定理
>	- $|G| = 6$, $|H| = 2$ 
>	- $[G:H] = 6 \div 2 = 3$
>- 陪集
>	- $0 + H = \{0, 3\}$
>	- $1 + H = \{1, 4\}$ 
>	- $2 + H = \{2, 5\}$
>- 结论
>	- 共有 $6 \div 2 = 3$ 个陪集, 符合指数 $[G:H] = 3$
