##### 范数
- 范数
	- **范数**是定义在[[向量空间]] $V$ 上的一个[[映射]] $\|\cdot\|: V \to \mathbb{R}$, 也是[[实函数|实值函数]], 为空间内的所有向量赋予长度或大小, 使其成为[[赋范向量空间]]. 范数对于 $\mathbf{u}, \mathbf{v}\in V$, $a\in\mathbb{F}$ 满足非负性, 齐次性和三角不等式, 如果放松非负性中的正定性, 则称为[[半范数]]. 范数是[[绝对值函数|绝对值]]的推广, 可以自然地诱导[[度量]]
		- 非负性, $\|\mathbf{v}\| \geq 0$, $\|\mathbf{v}\| = 0 \iff \mathbf{v} = \mathbf{0}$
		- 齐次性, $\|a \mathbf{v}\| = |a| \|\mathbf{v}\|$
		- 三角不等式, $\|\mathbf{u} + \mathbf{v}\| \leq \|\mathbf{u}\| + \|\mathbf{v}\|$
	- [[内积|内积范数]]
		- $||\mathbf{a}||=\sqrt{\langle\mathbf{a},\mathbf{a}\rangle}$
	- [[求和范数]]
		- $\|x\|_p = \left( \sum_{i=1}^{\infty} |x_i|^p \right)^{1/p}$
	- [[积分范数]]
		- $\|f\|_p = \left( \int_X |f(x)|^p \text{d}\mu(x) \right)^{1/p}$
	- [[一致范数]]
		- $\displaystyle \|f\|_{\infty ,S}=\sup \left\{\,|f(s)|\mid s\in S\,\right\}$
	- [[矩阵范数]]
		- $\|A\|_F = \sqrt{\sum_{i,j} |a_{ij}|^2}$
	- [[算子范数]]
		- $\|A\| = \sup_{x\neq 0} \frac{\|Ax\|}{\|x\|}$


>[!example]- 内积范数
>- 柯西-施瓦茨不等式
>	- ${\displaystyle |\langle x,y\rangle |\leq \|x\|\|y\|}$
>- 平行四边形定律
>	- ${\displaystyle \|x+y\|^{2}+\|x-y\|^{2}=2\|x\|^{2}+2\|y\|^{2}}$
>- 极化恒等式
>	- ${\displaystyle \|x+y\|^{2}=\|x\|^{2}+\|y\|^{2}+2\text{Re} \langle x,y\rangle }$
>-  托勒密不等式
>	- ${\displaystyle \|x-y\|\|z\|+\|y-z\|\|x\|\geq \|x-z\|\|y\|}$
>- 勾股定理
>	- $\displaystyle \|x\|^{2}+\|y\|^{2}=\|x+y\|^{2}$
>- 贝塞尔不等式
>	- $\displaystyle \sum_{n=1}^\infty |\langle x, e_n \rangle|^2 \leq \|x\|^2$
>- 帕塞瓦尔恒等式
>	- $\displaystyle \|x\|^2 = \sum_{n=1}^\infty |\langle x, e_n \rangle|^2$
