##### 空间直线
- 空间直线
	- **空间直线**是两个[[线性函数|三元一次方程]]交集对应的[[曲线]], 即两个非平行[[空间平面]]交线的点集, 通过两个不同的点可以唯一确定一条直线. 直线的方向由方向向量描述. 除此之外, 直线还可以通过多种[[图形关系]]来刻画, 可根据已知条件和应用场景选择适用的[[空间直线方程|方程形式]]
		- $\begin{cases}a_1 x + b_1 y + c_1 z + d_1 = 0 \\a_2 x + b_2 y + c_2 z + d_2 = 0 \end{cases}$
