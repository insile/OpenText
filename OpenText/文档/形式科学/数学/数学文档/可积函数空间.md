##### 可积函数空间
- 可积函数空间
	- **可积函数空间**是由所有 $p$ 次幂[[勒贝格积分|可积]]的函数构成的[[函数空间]], 记作 $L^p$, 配备[[积分范数]] $\|\cdot\|$ 构成[[赋范向量空间]]. 对于 $1 \le p < \infty$, 其标准范数为 $\|f\|_p = \left( \int_X |f(x)|^p \, \mathrm{d}\mu \right)^{1/p}$, 对于 $p = \infty$, 其标准范数为 $\|f\|_\infty = \text{ess sup}_{x \in X} |f(x)|$. 而 $L^p$ 空间在上述范数下均为[[巴拿赫空间]]. 特别地, 当 $p = 2$ 时, $L^2$ 空间是[[希尔伯特空间]], 配备[[内积]] $\langle \cdot,\cdot \rangle$, 定义为函数乘积积分. 设 $1 < p < \infty$, 若 $\frac{1}{p} + \frac{1}{q} = 1$, 则称 $p$ 与 $q$ 为共轭指数, 并且 $L^p$ 空间的[[对偶空间]] $(L^p)^*$ 与 $L^q$ 空间是[[等距映射|等距同构]]的 $(L^p)^* \cong L^q$. 当 $p=2$ 时, 共轭指数 $q=2$, 这说明 $L^2$ 是自对偶的
		- $\displaystyle L^p = \left\{ f: X \to \mathbb{C} \mid \int_X |f(x)|^p \mathrm{d} \mu(x) < \infty \right\}$
		- $\displaystyle \|f\|_p = \left( \int_X |f(x)|^p \text{d}\mu(x) \right)^{1/p} < \infty$
